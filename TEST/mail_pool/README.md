# Общий ящик на 20 ноября 2026 года

В ящике 57 писем. Каждая папка `Mxxx/` содержит одно письмо. Например, в `M012/` лежат [текст письма](M012/message.txt), [вход для RAG](M012/input.json) и банковское подтверждение `payment_confirmation.pdf`.

| Файл | Содержимое |
|---|---|
| [index.json](index.json) | Общий список с темой (`subject`), отправителем, получателем, датой и путями к тексту, JSON и вложениям |
| `Mxxx/message.txt` | Читаемый текст письма с заголовками |
| `Mxxx/input.json` | Метаданные и тело одного письма. Для RAG индексируются `subject` и `text`, а `from`, `to` и `date` можно использовать как фильтры |
| Остальные файлы в `Mxxx/` | Вложения из этого письма |

Для запроса по заявке агент получает её стартовый комплект из `../cases/TEST-xx/with_mail_search/`. В индексе нет готовой привязки писем к заявкам. Он позволяет отбирать письма по метаданным и открывать нужный `input.json`. Для поиска по содержанию в RAG используются записи из 57 файлов `Mxxx/input.json`.

Проверяющий сравнивает результат с `../reference/mail_pool_states/TEST-xx/`, где лежат ожидаемое действие и итоговый комплект документов. Карта ссылок на источники — [mail_pool_expected.json](../reference/mail_pool_expected.json). Для пяти заявок достаточно проверить документы в стартовых материалах, поскольку подходящего письма в ящике нет. Отсечение для всех кейсов — 12:00 по Москве.
