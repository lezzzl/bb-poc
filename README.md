# PoC помощника по сопровождению клиентских заявок

Учебный прототип (НИС «Информационная бизнес-аналитика», команда 07). Один запуск разбирает один эпизод одной заявки: помощник ищет материалы заявки в синтетическом почтовом ящике, готовит сводку со ссылками и предлагает следующий шаг. Код проверяет ссылки, принадлежность и допустимость перехода, сотрудник принимает или исправляет результат. Решение пишется в тестовую карточку и журнал замера.

Все данные в `TEST/` вымышленные. Модель вызывается через OpenRouter — только на синтетических данных.

Зафиксированная версия для замера — тег `poc-v2`, подробности в [docs/poc-frozen-version.md](docs/poc-frozen-version.md).

## Установка

Нужен Python 3.12+.

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
cp .env.example .env    # вписать OPENROUTER_API_KEY
.venv/bin/pytest tests/poc -q
```

## Страница для сотрудника

```bash
.venv/bin/streamlit run poc/app.py --server.address 127.0.0.1 --server.headless true --browser.gatherUsageStats false
```

Открыть http://127.0.0.1:8501. Ввести имя участника, выбрать кейс и режим («с помощником» или «вручную»), нажать «Старт» — пошёл таймер.

- **С помощником:** через 15–35 с появляется сводка. Источники выводов открываются кнопками. «Принять», «Принять с правками» или «Отклонить».
- **Вручную:** слева весь ящик (57 писем) с поиском, справа та же форма. «Сдать».

Для замера можно положить `TEST/assignments.csv` (`participant,order_no,case_id,mode`, где `mode` — `manual` или `assistant`): страница сама выдаёт участнику следующее задание.

## Командная строка

```bash
.venv/bin/python -m poc run TEST-20                 # один кейс
.venv/bin/python -m poc batch --set holdout         # все закрытые кейсы (holdout | development | all)
.venv/bin/python -m poc eval                        # сверка последних прогонов с эталонами
.venv/bin/python -m poc export-blind poc_data/blind.jsonl   # результаты для слепой оценки
```

Журнал и тестовые карточки — `poc_data/poc.sqlite` (создаётся при первом запуске).

## Как устроено

| Файл | Что делает |
|---|---|
| `poc/scope.py` | область доступа: только материалы этой заявки и клиента до момента отсечения |
| `poc/index.py`, `poc/tools.py` | поиск SQLite FTS5 и инструменты агента: `list_sources`, `search`, `get`, `signatures`, `next_step_rule` |
| `poc/graph.py`, `poc/prompts/agent_system.txt` | граф LangGraph: агент → проверка → остановка на сотруднике → сохранение |
| `poc/validate.py`, `poc/transitions.py` | проверки кодом: ссылки, принадлежность, переходы по таблице статусов, подписи |
| `poc/journal.py` | тестовые карточки и журнал замера |
| `poc/app.py` | страница Streamlit |
| `TEST/` | 32 синтетических кейса, общий ящик, эталоны (см. `TEST/README.md`) |
| `docs/` | дизайн, план реализации, описание зафиксированной версии |
